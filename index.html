使用说明

为什么主库现在只看近30天？

超过30天的内容默认不进入主库，避免一年以前的爆款逻辑干扰当前剪辑判断。若某条旧广告仍在 Meta Ads Library 明确持续投放，后续才会作为“持续投放例外”重新纳入。

现在的主库为什么不会再出现“空视频卡片”？

程序会自动过滤掉没有 Instagram shortcode 或 TikTok video ID 的案例。也就是说：只有能在卡片左侧嵌入播放器的视频，才有资格进入主库。每张卡还提供备用镜像切换。

为什么 Meta Ads Library 不能直接嵌入本地网页？

Meta 广告资料库有登录、跨域和内容安全策略限制，静态本地 HTML 不能稳定把广告播放器嵌进 iframe。因此这里使用官方 Ads Library 直达入口，而不是做一个看似能播但经常空白的播放器。

“可能提升 CTR / 3秒留存”是什么意思？

这是剪辑策略假设，不是竞品公开后台结论。真正是否有效，要用你自己的 Meta / TikTok 数据做 A/B Test 验证。
